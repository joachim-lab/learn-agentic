# Glossary

Plain-language terms, added as they appear in lessons.

- **repo** — a folder whose history git records. (L001)
- **commit** — one recorded snapshot of the repo, with a message. (L001)
- **stage** — mark a change for inclusion in the next commit. (L001)
- **push** — send local commits to the copy on GitHub. (L001)
- **diff** — the line-by-line difference between two versions. (L001)
