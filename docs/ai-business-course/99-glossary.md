# Glossary — AI for Business with Claude

Plain-language definitions. The module in brackets is where the term is taught.

- **A/B test (of a skill)** — run two versions of a skill on the same input and compare tokens, time and quality. [07]
- **Agent** — a model using tools in a loop until a goal is met. [11]
- **Agent file / agent.md** — a file that defines a worker: role, tools, model, instructions. Skills refer to it. [11, 15]
- **Agent team** — several agents that share a task list and message each other. Claude Code feature. For interdependent work. [11, 15]
- **AGENTS.md** — Codex's standing-instruction file. Equivalent of CLAUDE.md. [10]
- **Artifact** — anything Claude makes that you would put in front of someone: doc, deck, dashboard, tool. Lives in the Artifacts tab. [09]
- **Auto mode** — permission mode where a classifier reviews each action and blocks risky ones. [14]
- **Brain / context layer / second brain** — folders of Markdown files that hold what the business knows, organised so agents can read and write them. [04, 05]
- **Brief** — the conversation before the work: goal, constraints, what good looks like. Plan mode. [03]
- **Capture → curate → store → execute → experience** — Theo's loop for how context flows in an AI-native business. [04]
- **Chat / Cowork / Code** — the three shapes of work in the Claude desktop app: think with, delegate to, build with. [02]
- **CLAUDE.md** — the router-plus-rules file at the root of a folder. Under 200 lines. Read by Cowork and Claude Code. [05]
- **Cloud agent / cloud session** — an agent running on the vendor's servers in its own virtual machine. Keeps running when your laptop is off. [06, 13]
- **Command** — one file that runs several skills in sequence. Invoked with `/name`. Same idea as a skill chain. [07, 15]
- **Computer use** — Claude sees the screen and clicks. Slowest and most expensive access method. Last resort. [08]
- **Connector** — a link between Claude and another tool (Gmail, Drive, Slack...). An MCP server under the hood. [08]
- **Context** — everything the model can see when it answers. Also: the business knowledge written down for agents. [01, 04]
- **Context engineering** — putting the right slice of the context layer into the context window at the right moment. [04]
- **Context window** — the fixed amount of text a model reads at once. About 500 pages for Claude. [01]
- **Deploy** — put a new version where users use it. Human-owned. [06, 14]
- **Dev / exec / prod** — where you try things / the deployment users open (Apps Script) / what users use. [06]
- **Diff** — the before-and-after of a change, line by line. Read it before you accept. [10]
- **Dispatch** — trigger Cowork on your desktop from your phone. [13]
- **Eval** — a measured check of what the agent produced against a standard. [07, 11]
- **Eyes** — the agent inspecting what it built: preview, click-through, tests, logs. [03, 10]
- **Frontmatter** — the metadata block between `---` lines at the top of a Markdown file. [05]
- **Global preferences / instructions** — standing instructions that apply to every chat or every Cowork session. [02]
- **Hallucination** — plausible text with no fact behind it. Reduced by context, tools and verification. [01]
- **Hook** — a shell command that always runs at a fixed point in the agent's work. Deterministic. [08, 14]
- **Human-in-the-loop (HITL)** — a checkpoint where the agent stops and a person decides. Cowork shows it as a question with options. [07]
- **Librarian** — the curation step or agent that files inbound information into the brain and detects triggers. [04, 15]
- **LLM (large language model)** — a program trained to predict the next token; the engine behind Claude. [01]
- **Manual mode** — permission mode where the agent asks before each action. [14]
- **MCP (Model Context Protocol)** — the open standard for connecting AI applications to tools and data. "USB-C for AI". [08]
- **MCP server** — all the actions of one tool bundled so any agent can use them. [08]
- **Memory (Claude)** — a small set of facts Claude keeps about you across chats. Not a replacement for the brain. [02]
- **Metadata** — data about data: title, date, status, source, project. Lets an agent decide whether to read a file. [05]
- **Model routing** — using the strongest model to plan and review and cheaper models for bulk and loops. [01, 15]
- **Morning brief** — the first routine to build: a read-only daily summary with one recommended action. [12]
- **Orchestrator** — the manager agent that splits a goal, spawns children, and reviews their returns. [11, 15]
- **Permission tiers** — safe (do freely) / ask first / human-owned. [14]
- **Plan mode** — the agent reads the context and proposes an approach before touching anything. [03]
- **Plugin** — a bundle of skills, commands, agents and connectors for one role or department. Shareable and versionable. [15]
- **Progressive disclosure** — only a skill's name and description are always loaded; the body and references load when needed. [04, 07]
- **Project** — a workspace with its own chats, knowledge files, instructions, memory and (in Cowork) folder. [02]
- **Prompt injection** — instructions hidden in content the agent reads, aimed at making it act against your intent. [14]
- **Reference file** — a file inside a skill (or in the brain) that a step of the skill reads: examples, style guide, tool instructions. [07]
- **Repo** — a folder whose history git records. The agent's workspace, memory and undo button. [06]
- **review.md** — the file that says how to judge work before it ships. Yes/no questions. [14, 15]
- **roadmap.md** — the file that says what matters this week and what is out of scope. [15]
- **Routine / scheduled task** — a prompt sent to a fresh session on a schedule. Cowork: Scheduled tab. Claude Code: Routines. Codex: Automations. [12]
- **Sandbox** — an isolated machine where the agent works. Your folders may be mounted inside it. It is not your computer. [06]
- **Self-improvement loop** — grade yesterday's output on a rubric, open fixes for anything below the bar, human ships. [12]
- **Signal** — what the market tells you when it uses your output. Flows back into the brain. [04]
- **Skill** — a folder of instructions, scripts and resources Claude loads when a task matches. Your process as software. [07]
- **Skill chain** — a macro skill that fires several skills in order. [07, 15]
- **SKILL.md** — the process file of a skill. Frontmatter: name, description. Keep it clean. [07]
- **Sub-agent** — a helper with its own fresh context window and tool list. Returns only a summary. [11]
- **System of record** — where the truth of one kind of data lives (the ERP sheet, the CRM). The brain points to it. [05]
- **Ticket** — a small assignment with a job, a scope, an expected result and a boundary. [03]
- **Token** — a piece of a word. About 750 words per 1,000 tokens. The unit of cost and of the context window. [01]
- **Tool** — a function the model can call: search, read, write, send. [08]
- **Traces / exhaust** — the drafts, decisions and dead ends produced along the way. Worth filing. [04]
- **Trigger** — an event that starts a loop: an email, a transcript phrase, a pull request. Polled when no instant trigger exists. [12]
- **Watchdog** — a daily routine that summarises what happened in your most important system, with links to evidence. [12]
- **Worktree** — a separate working copy of a repo so several agents edit without collisions. [06]
- **Write-back** — agents writing to the brain: logs, decisions, rules, approved examples. [04, 12]
- **4Ds** — Delegation, Description, Discernment, Diligence. Claude Academy's AI fluency framework. [01]
